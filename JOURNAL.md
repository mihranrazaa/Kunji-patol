# May 29 : IRL Build 
So after a long long break i'm back!!!!
I ordered the parts which i didn't have which is only pcb heheh, i had all the stuff already i had to wait for my pcb for a long time as a from where i ordered it from though is the cheapest option but it takes 15-20 days to arrive, so it took its sweet time, after it arrived i started with soldering the diodes, then swtiches. i didn't had any problems soldering diodes but man the switches uh
I could only solder two or max 3 switches at time, as they were so loose on pcb + i didn't had any helping hand tools to make the process easier i tried using tape 3 times all the time it failed miserably. anyways i completed soldering switches after that i solder my MCU RP2040 plus, that was very easy and i enjoyed that, then my rotary encoder had already soldered pins so i had top remove them as  they were bent and were upside down but while removing the pad came out of clk pin so i have to reorder it till then i made a firmware for the keyboard i started with normal QMK based firmware but later added VIA functionality which is peak literally as that does not require flashing firmware again and again. SO only few things remians, the rotary encoder, and the base case which i will redesign  after doing some research on how much incline is better for keyboard, though i'm writing this with my keybaord only :) it works amazing!! it feels very different from my laptop membrane keyboard, plus the SOUND !!, anyways that's all i'll update when i start with the new case design and when i order my new rotary encoder. 
That's all for now..
